# RYN-AI-Speed v2.0: خريطة الإنجاز وخطة التنفيذ (P0 – تدقيق المشروع)

هاد الملف هو الخطوة الأولى بخطتك: تدقيق الموجود، تحديث خريطة الإنجاز، وبعدها ترتيب التنفيذ.
الرموز: ✅ منفّذ ومجرَّب بالاختبارات | 🟡 منفّذ بس ما اتأكدنا منه على جهاز حقيقي أو بالـCI | 🔶 جزئي | ❌ غير موجود.

## 1) قرارات لازم نثبّتها (فيها اختلاف بين الخطة والكود)
1. **Windows: WPF أو WinUI 3؟** الخطة بتقول WinUI 3 والكود الحالي WPF (والـCI شغال عليه). **القرار المقترح:** نكمل بـWPF لأنو أثبت وأسرع بالبناء، وWPF بيدعم MSIX والتوقيع. نعيد التقييم بعد P8.
2. **شات AI مستقل:** الخطة بتقول مو لازم. أنت طلبته قبل (مثل Gemini) وهو مبني على Android. **القرار المقترح:** نخليه صفحة ثانوية اختيارية، وأولويتنا Smart Core بالخلفية.
3. **الإنجليزي والعربي:** كل النصوص الحالية عربية ثابتة داخل الكود. لازم ننقلها لملفات ترجمة قبل P1 (Android strings.xml وWindows Resources).
4. **سيرفرات VPN:** بدون سيرفرات WireGuard حقيقية ما في VPN حقيقي. لازم قرارك (سيرفراتك أو مزوّد).
5. **README قديم:** كان يقول "P0 مكتمل". صار هاد الملف هو المرجع.

### Backend (P6)
- ✅ FastAPI + JWT Ed25519 + Argon2id + تدوير Refresh Token + حدّ معدل + حسابات دائمة (SQLite).
- ❌ PostgreSQL وRedis موجودين بالإعداد وغير مستخدمين.
- ❌ سجل سيرفرات VPN وفحص صحتها: بالذاكرة فقط وبلا استمرارية.
- ❌ إدارة الأجهزة، التحقق من السيرفرات المجتمعية، إدارة الإصدارات.

### Smart Core (P7)
- 🔶 قواعد محلية بسيطة (تشخيص الشبكة) + سجل أدوات بصلاحيات READ/SAFE_ACTION/PROTECTED_ACTION (موجود بالـbackend).
- ❌ لا يوجد حلقة قرار بالخلفية، ولا قياس نتيجة القرار، ولا سجل أداء، ولا "تفسير" للقرار.

### الواجهة (P1)
- 🟡 Android (نُفّذ، بانتظار الـCI والتجربة): قائمة جانبية موحدة (8 أقسام)، شاشة رئيسية بخريطة عالمية وحالة الاتصال وإحصاءات، صفحة تحسين الإنترنت، صفحة Smart Core (قراءة فقط)، صفحة إعدادات، عربي/إنجليزي مع RTL/LTR بدون إعادة تشغيل، أيقونة.
- 🔶 Android: شاشة التنزيلات (وحدة feature) بقيت نصوصها إنجليزية، وتحتاج نقل لنظام اللغتين.
- ❌ Windows: القائمة الجانبية والخريطة وباقي التبويبات (التنزيلات فقط بالشكل الجديد).
- ملاحظة: الخريطة مرسومة بكود (مضلعات مبسّطة للقارات) وليست أطلساً دقيقاً.

### الأمان والتطبيق (حسب قسم 7)
✅ SQLCipher + Keystore (Android) • ✅ DPAPI (Windows) • ✅ Argon2id • ✅ Ed25519 • ✅ حماية SSRF/Path Traversal (مع إصلاح DNS-rebinding) • 🔶 عزل المتصفح • ❌ توقيع/تحقق التحديثات • ❌ سجل Smart Core.

### الأداء والاختبارات (P9)
كل أرقام الميزانية (بدء التشغيل < 1.5 ث، الاستكمال < 2 ث) **غير مقاسة**. الموجود: اختبارات Python (backend/عقود/أمان) ✅ ونجحت، واختبارات Kotlin وC# بتشتغل بالـCI بس. ما في أي اختبار على جهاز فعلي.
